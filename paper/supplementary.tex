\subsection{Runtime and inference}

\begin{itemize}[leftmargin=*]
    \item Hardware: four NVIDIA GeForce RTX 4090 GPUs (24,564 MiB reported per GPU), 44 vCPU, 240 GB RAM.
    \item Software: Ubuntu 24.04.1 LTS; Python 3.12.3; PyTorch \texttt{2.7.0a0+7c8ec84dab.nv25.03}; Transformers 4.57.1; CUDA runtime 12.8; cuDNN 9.8.0; driver 550.54.14.
    \item Execution: four independent scene-level shards, one process/GPU, batch size one.
    \item Generation: greedy, \texttt{do\_sample=False}, maximum eight new tokens, EOS or length stopping.  Temperature is not passed and is inactive.
    \item Final controlled-natural answers use mean conditional candidate log likelihood with \texttt{use\_cache=False}; they are not free-form generations.
    \item Seeds: 20260927 for the final synthetic dataset and primary analyses; deterministic SHA-256 salt \texttt{final-natural-v2-marker-locked} for the controlled-natural selection.
\end{itemize}

\subsection{Statistical protocol}

\begin{itemize}[leftmargin=*]
    \item Independent resampling unit: scene.
    \item Uncertainty: nonparametric percentile 95\% CI from 20,000 scene-bootstrap draws unless noted.
    \item Paired binary outcomes: two-sided exact binomial test on discordant pairs.
    \item Multiplicity: Holm correction over the prespecified E12--E14, E16, E17, and E18 families; E11 exploratory cross-model effects were not multiplicity corrected.
    \item E19 diagnostic correlations use up to 5,000 resamples and are not confirmatory.
    \item E18 and E19 reuse E17 predictions.  Their scene counts must not be added as independent evidence.
\end{itemize}

\section{Intervention Details}

\subsection{Formal definition}

Given post-encoder visual content $F=(f_1,\ldots,f_n)$ and interface positions $P=(p_1,\ldots,p_n)$, define
\begin{align}
\text{canonical}:&(F,P), &
\text{content-only}:&(\pi(F),P),\\
\text{position-only}:&(F,\pi(P)), &
\text{joint}:&(\pi(F),\pi(P)).
\end{align}
Clarify that $\pi$ acts on selected coherent blocks; tokens outside the movable subset remain canonical.

\subsection{Qwen implementation}

\begin{itemize}[leftmargin=*]
    \item Logged vision grid $1\times54\times54$; merged language-model grid $27\times27$, 729 visual tokens.
    \item Four $13\times13$ corner blocks move (676 tokens); center row and column remain fixed (53 tokens).
    \item Content hook: post-encoder image features.  Position hook: all visual coordinate axes returned by M-RoPE index construction.  Reset \texttt{rope\_deltas} before each example.
    \item Content-only fixes M-RoPE; position-only fixes features; joint applies the same destination-to-source block permutation to both.
\end{itemize}

\subsection{LLaVA implementation}

\begin{itemize}[leftmargin=*]
    \item Packed layout: 729 thumbnail tokens plus a $54\times55$ high-resolution matrix, comprising 2,916 content tokens and 54 newline tokens; total 3,699.
    \item Four $27\times27$ high-resolution blocks move.  Thumbnail and newline tokens remain fixed.
    \item Position-only changes scalar language-model sequence position IDs, not SigLIP's internal 2D positions.
    \item Content/position hooks execute after the vision encoder/projector at the packed interface.
\end{itemize}

\subsection{Hook validation}

Document \texttt{--debug-hooks} / \texttt{DEBUG\_HOOKS=1} and archive JSON records containing execution status, tensor shape, token count, permutation ID, and SHA-256 checksums before/after the hook.
Canonical conditions should preserve checksums; permuted conditions should preserve shape/count while changing byte-order checksums.

\section{Additional Controls and Falsification}

\subsection{Matched four-object recognition}

\begin{itemize}[leftmargin=*]
    \item 96 LLaVA scenes; prompt: ``What shape is the \{color\} object?''; four-shape closed answer set.
    \item Canonical/permuted recognition: 100\%/100\%.
    \item Canonical/permuted binary relation: 93.75\%/68.75\%; degradation $25.00$ pp, 95\% CI $[16.67,33.33]$, exact $p=1.19\times10^{-7}$.
    \item Limitation: closed-set recognition remains at ceiling and does not equalize every operation with spatial reasoning.
\end{itemize}

\subsection{Exhaustive four-region topology}

Enumerate all 24 permutations: identity, seven nonidentity $D_4$ grid automorphisms, and sixteen adjacency-breaking permutations.
Report primary breaking-minus-preserving contrasts and named graph-preserving counterexamples.
Limit every conclusion to the unweighted four-node 2$\times$2 adjacency graph.

\subsection{Inference-time augmentation}

Define S0 identity, S1 180-degree reverse, S2 90-degree rotation, S3 column-major transpose, and S4 fixed random-breaking $(0,3,1,2)$.
Report the unweighted modal vote with canonical fallback for multiclass ties, repeated-S0 and random-answer controls, and the unattainable any-view oracle.
The result is negative for this vote; no calibrated or learned selector was tested.

\subsection{Serialization disagreement}

Report pairwise agreement, unanimity, Shannon entropy, normalized entropy, random-view accuracy versus disagreement, and canonical-error diagnostics.
Required caveat: disagreement and random-view accuracy are computed from the same five predictions and are mathematically coupled.
Do not label disagreement as calibrated uncertainty.

\subsection{Generic query-order control}

\begin{itemize}[leftmargin=*]
    \item 96 LLaVA scenes; compare canonical, post-encoder visual content permutation, and a four-block query-embedding permutation.
    \item Visual degradation: recognition/binary/composition $0/25.00/25.00$ pp.
    \item Language degradation: $0/51.04/69.79$ pp.
    \item The language control changes word order and therefore query semantics.  It is a destructive generic-order baseline, not a semantics-preserving control.
    \item Required conclusion: the experiment does not show that visual serialization is uniquely more harmful than generic sequence order perturbation.
\end{itemize}

\subsection{Established-benchmark pilot}

Report the 60-scene VSR subset only as an inconclusive pilot: canonical recognition-like/spatial accuracy is 46.67\%/51.67\%; spatial degradation is 6.67 pp, but the exact paired $p=.125$ and both baselines are near chance.
Do not use it as confirmatory natural-image evidence.
