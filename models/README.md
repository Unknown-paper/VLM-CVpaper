# Model checkpoints

No model weights are stored in this repository. Supply a Hugging Face model ID or local checkpoint path through `LLAVA_MODEL`, `QWEN_MODEL`, or `INTERNVL_MODEL`.

The completed main runs used FP16 LLaVA-OneVision-7B, BF16 Qwen2.5-VL-7B, and BF16 InternVL3-8B. Exact immutable checkpoint revisions are `UNKNOWN`; see `configs/models.yaml` and `REPRODUCIBILITY.md`.
