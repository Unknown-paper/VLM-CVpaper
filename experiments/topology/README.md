# Exhaustive topology experiment (E17)

`build_manifest.py` enumerates all 24 permutations of four regions on a locked, orientation-balanced 192-scene subset. The analysis compares seven nonidentity adjacency-preserving permutations with sixteen adjacency-breaking permutations and reports named counterexamples plus continuous topology correlations.

This test reuses a locked subset of the synthetic benchmark; it is not an independent dataset replication.
