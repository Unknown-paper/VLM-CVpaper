# Serialization augmentation and disagreement (E18–E19)

The analysis selects canonical S0 plus four fixed serialization variants S1–S4 from E17 predictions. It computes fixed-view accuracy, modal voting with canonical tie fallback, pairwise agreement, unanimity, entropy, accuracy versus disagreement, and error AUCs.

The same predictions are reused for E17–E19. Disagreement is interpreted as a serialization-instability signal, not calibrated confidence or causal evidence.
